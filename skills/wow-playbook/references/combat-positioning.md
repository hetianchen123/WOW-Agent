# 战斗站位与选敌

以下为 **玩家操作参考**。按实际使用技能的射程、施法条件、队伍分工和当前机制选站位。猎人自身的攻击范围与宠物能否接敌分别判断。团本和大秘境示例来自正式服公开视频，当前文档记录供设计和排错使用。

## 远程与近战怎么站

| 场景 | 远程输出 | 近战输出 |
| --- | --- | --- |
| 野外任务 | 从有视线、技能够得到的开阔位置开打，旁边留一条可移动路线。超距时短步靠近，够距离后停下。敌人靠近时按实际危险决定原地继续、横移或拉开，移动时只使用当前允许移动施放的技能。 | 从有路的一侧接近，看到主要技能进入有效距离后停步。围绕当前目标小幅横移修正朝向，保留其他怪的动向。遇到正面技能或地面伤害预警时移开，安全后从可通行一侧贴回。 |
| 团本开打与常规输出 | 按团长分组、标记和机制站位。尽量同时看见首领、脚下和即将去的位置。原地能读条时稳住，提前为下一次集合、分散或跑位留路径。 | 坦克接稳后进近战范围。常规站侧后方并保持角色朝向目标，首领转向时跟着安全侧小移。遇到尾击、分摊、点名或指定站位，以当前机制和分工决定去向。 |
| 大秘境换波与输出 | 跟随坦克路线进场。拉怪期间保留视线和支援距离，按队伍节奏等怪到可输出位置。用就近安全位置打当前优先怪，换波时给队伍转场让出通路。 | 给坦克留引怪和调整朝向的空间。怪聚近后从安全侧进入，遇到正面喷吐、旋转技能或圈先移到安全侧。换波时沿已确认的过道跟队，避免碰到旁边未进战的怪。 |

- 走位和输出交替时，先确认需要移动的原因、方向和停止点。危险即将命中时及时走位。安全后核对原目标还活着、角色朝向、射程与视线，再继续输出。目标超距、朝向错误和视线遮挡分别用接近、转身和换位置处理。
- 同一地面提示可能要求离开、集合分摊，或由指定队员处理。先根据首领提示、己方点名、队伍站位与已知分工解释提示。安全路径临时经过近战区或需要离开输出范围时，跟随机制结束再恢复原站位。

## 战斗镜头怎么选

**代码已实现，待实测（0.2.61）**：任务主循环根据插件报告的公开专精选择远程/近战取景，兽王为远程、生存为近战。到任务区域时先准备镜头，进入战斗后只做非阻塞缩放，未知专精不猜测站位方式。镜头不改变目标或角色朝向；距离确认不能证明脚下与目标均可见。战后交互和拾取期间让出控制，结束后按当前任务恢复。团本/大秘境没有机制专用镜头自动化。

- **远程**。适度拉远并稍俯视，保留角色脚下、目标和去下一站位的横向通路。只有目标在远处、脚下被界面挡住时，先调俯角或拉远。进入读条窗口后保持画面稳定。
- **近战**。用能同时看到脚下、敌人正面和怪群外沿的俯视角。怪物模型遮满屏幕时稍拉远或从侧面取景。狭窄房间遇墙面挤镜头时略缩短距离并换角度，始终保留脚下可走地面。画面朝向改变后复核角色是否仍面向敌人。
- **需要重新找敌**。先查当前目标框和可见姓名板，再从同侧平缓转镜头，停稳后确认。候选被模型或叠在一起的姓名板挡住时，优先换到已知可通行的观察点。鼠标只核对有识别依据的候选。任务巡航角度与按场景取景见[移动与视角](navigation.md)。

## 什么时候切目标

1. **开打前选定目标**。野外优先确认任务要求和当前参战关系。队伍场景按分工、团队标记、已确认的优先怪或机制目标选择。确认目标活着、可攻击，并检查射程和视线后再输出。
2. **有理由再切**。当前目标确认死亡，或已确认要处理的高优先级小怪、转火目标、读条出现时切换。单纯丢了一帧目标或短暂超距时先核对原目标，保留任务进度和原目标身份。目标仍活着且继续有效时保持选中。
3. **按反馈确认切换**。优先直接选可确认的姓名板。鼠标悬停核对后再点选，重叠时等清晰或换观察点。Tab 用于有界候选搜索，每次按完读取目标框或可读身份。核对完整 GUID 或目标变更序列、存活和参战关系，尤其是同名怪；识别受限时保留未知。确认选中后才用攻击或控制技能。
4. **把打断与控制分开**。先核对谁负责、读条是否可打断、技能是否就绪和能否够到目标。只有明确能受相应控制的敌人，才在需要时用晕等控制处理特定读条。若已配置并确认焦点或鼠标指向及相应绑定，可按分工处理副目标，处理后复核主目标。没有确认读条停止或出现相应反馈时，保留结果未知。
5. **收尾再决定下一步**。野外同一场战斗结束后统一拾取并复查任务追踪。团本看击杀提示。大秘境在转场时保留对队伍位置、敌方部队进度和首领进度的观察，最终用钥石结算确认完成与是否限时。
