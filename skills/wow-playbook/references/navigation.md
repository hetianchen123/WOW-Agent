# 移动与视角

本文件是用户要求和开发验收准则，不代表全部能力已经实机通过。

## 路线与旅行方式

- 先确定当前地图、目标地图、楼层/室内外、角色位置、目标来源和位置时效。地图坐标是方向参考，入口、楼梯、桥梁、墙体、悬崖需要局部路径证据。
- 默认优先级：可用飞行 → 地面坐骑 → 步行。短距离接近目标不反复上马；需要进屋、精确互动时落地再下马。跨地图没有连接路线时明确报告，不把两个地图的归一化坐标直接相减。
- 驭空术在上坐骑后核对实际动作栏和技能，再决定升空、加速、急停、下降。不能因未上马时看不到技能就认定不可用，也不能永远假定 1–5 是相同技能。
- 飞行提前减速，选开阔落点；建筑旁避免一直俯冲。按落地状态确认后下马。无落地证据时不能仅凭抵达二维坐标使用下马键。
- 接近目的地逐步缩短前进脉冲，停下来再观察；距离变远或角度明显偏离时先修正朝向，避免跑过后再大幅折返。

## 小地图和画面

- 小地图用于验证相对方向、任务标记和目标变化；先识别缩放、旋转模式、角色箭头及屏幕位置。世界地图坐标转换距离需要当前地图尺度。
- 黄色标记可能是目标区域或不同类型目标。结合任务进度、提示及场景确认，不能直接当作某个南瓜的可点击中心。
- 标记消失不代表已拾取；记录最后位置并有限度复查，再转局部搜索，避免以无关的旧路线点为中心继续兜圈。
- 搜索镜头保持第三人称、较宽视野、可见地面和前方目标；镜头被墙挡住或贴近角色时先恢复可观察视角。转镜头不必然改变角色朝向，输入方式要明确。
- 用户明确要求不频繁高速晃动视角。找怪、找 NPC 和战斗朝向纠正使用有节奏的小步转向，释放转向键后观察新状态；不要按 `+30°、-30°、+65°、-65°` 一轮轮扩大摆动。优先顺着同侧扇区观察，再平缓转向另一侧；找到有效目标即停止搜索转向。
- 当前找怪/NPC/战斗转向脉冲为 0.06 秒，两次脉冲至少间隔 0.45 秒；到达观察方向后至少稳定 0.5 秒再选敌或重试输出。旧路线鼠标转向单次最多 40 像素、至少间隔 0.45 秒。参数已加回归约束，真实镜头舒适度待实测，不保证不同客户端转向速度一致。

## 卡住后的升级顺序

卡住由连续位置变化、目标距离和动作反馈判断；模型推理等待、施法、拾取、主动停步不能算碰撞。

1. 释放持续前进，查看前方是否是可跳越的小障碍。安全地面上优先短步＋跳跃。
2. 同侧小幅调整方向或镜头，确认通路后短步＋跳跃。一次只试一个可验证动作。
3. 有侧方空间时左右横移；先验证横移键，不能把转身键当横移。
4. 后方安全时退到最近的开阔位置，重新选择入口或绕行点。
5. 重复无位移/同一障碍失败达到配置阈值后，从单视角升级到左、右及必要的后方多视角。每个方向平缓转动、停稳再采样，不能为凑多张截图快速来回甩镜头。记录每次旋转和相对朝向，以统一坐标比较候选路线；优先保留已有可通行方向，不因“这一侧看过”就否定新证据。
6. 可见路线仍无进展时结束该局部尝试，报告位置与原因，避免无上限左右摆头和撞墙。悬崖、水域、飞行及不可判断地面时不盲目跳跃或后退。

## 验收

任务中死亡先停止当前移动和战斗，点击游戏确认的释放灵魂按钮。灵魂状态读取当前地图的尸体位置，沿地面路线跑到附近。复活提示出现后停步，等确认按钮可用，鼠标悬停得到插件的新反馈后点击。以角色恢复存活为准，再完成职业准备并重新规划原任务。缺少尸体路线或正确弹窗时明确停止，禁止用鼠标盲找。

空地朝向修正、近距离刹停、木楼梯/墙角绕行、驭空术落地分别测试。记录前后位置、距离、朝向、恢复级别和次数；“执行了转向”不能作为“绕过障碍”的成功标准。
