# 《魔兽世界：无限》(WoW: Forever) 可行性分析

> 2026-11-06 调研。承接 `PLAN.md`（正式服方案），评估新上线的「无限」服务器是否值得切换/并行：技术路线可行性、收益对比、金币/时光徽章变现路径。

## 0. 三问三答

| 问题 | 结论 |
|---|---|
| 技术路线可行吗 | **可行，且参考项目更贴合**（WowClassicGrindBot 本身就是 Classic 客户端架构），但**无飞行 + 地面怪物 + 节点竞争 + 跑尸**使导航层工程量比正式服方案重 30–50% |
| 收益更高吗 | **金币收益短期（首月）大概率更高，人民币收益存疑**：新服消耗脉冲（12/9 团本开荒）推高材料价，但金价无官方锚定、灰价低（~0.02–0.03 元/金）、无变现出口，且经典服脚本是重灾区，红利会被竞争摊薄 |
| 方便金币/徽章变现吗 | **目前变现闭环断裂**：官方明确无限服**初期不加入时光徽章**（也无角色直升），金币没有任何官方出口，连「金币换月卡」都不行；跨服徽章互不流通。正式服的金币→徽章→游戏时间是唯一官方出口，且同样**不能提现人民币** |

**建议：主线维持正式服方案不变；无限服做「人工观察 + 条件触发」的备线**（见 §5）。

## 2. 技术路线可行性（对照 PLAN.md 逐模块）

总体判断：**「插件色块通道 + OpenCV + 键鼠模拟」架构原样适用**，且 WowClassicGrindBot 这个最完整的开源参考本来就是 Classic 客户端的——比正式服更"同族"。差异集中在导航层。

| 模块 | 无限服情况 | 对 PLAN.md 的影响 |
|---|---|---|
| 客户端底子 | Classic 系客户端（Classic+ 分支） | 截图/键鼠/架构不变；需新建 Classic 端模板库 |
| 位置/朝向 API | Classic 客户端保留位置 API（WowClassicGrindBot 即靠它导航），具体函数与精度需 PoC | PoC #4 重做一遍（半天） |
| 状态通道 | 插件机制同源，Lua API 表面略旧 | 通道设计不变，改字段 |
| 钓鱼 | 经典机制：鱼竿+鱼饵、右键点鱼漂收竿（无正式服软目标互动键） | 改为**像素定位鱼漂+右键点击**（pixel-bot 成熟做法），音效识别不变 |
| 采集 | **无飞行**（vanilla 规则，地面坐骑）；节点先到先得（非个人） | **最大差异**：地面路线穿怪区 → 需避怪路线设计或战斗处理；死亡跑尸是难点（经典死亡→灵魂状态跑尸） |
| 导航 | 地面-only + 怪物 + 竞争 | **"不做 navmesh"的决策在无限服大概率要推翻**：地面+怪环境下导航网格价值大增（WowClassicGrindBot 用 navmesh）；或接受更密的航点+更强的卡死恢复 |
| 拍卖行 | Classic 老 AH API，Auctionator 有 Classic 版 | 售卖模块流程不变 |
| 入场成本 | **无直升**：需人工练 1→60 + 采集专业 300 + 坐骑金 | 一次性沉没成本（人力），自动化前的硬投入 |
| 工程量估算 | — | 相对正式服方案 **+30–50%**（战斗/避怪/跑尸/navmesh），约 26–46 个工作日 |

结论：技术可行，无架构级障碍；难点从正式服的"飞行高度控制"变成"地面生存与竞争"。

## 3. 收益对比分析

**今天开服第 2 天，不存在可靠收益数据，以下为框架判断：**

利好（短期）：
- 新经济体+全员冲级/冲专业 → 材料、消耗品需求脉冲；**12-09 团本开放是第二个消耗高峰**（开荒合剂/药水/附魔/抗性装）
- 供给端采集号少（练号门槛高）→ 首月材料价格通常数倍于稳态

利空：
- **金币无官方锚定**（无徽章）→ 灰市定价，怀旧类金币灰价约 0.02–0.03 元/金（2024 年底大跌后量级），且有"网易直接卖金压金价"的社区说法（**未证实**，待观察）
- 经典服历来是脚本重灾区，开服红利会被机器人摊薄；暴雪 4 月刚关停 Turtle WoW，对 Classic+ 管控姿态偏严
- 3–6 个月后经济回落稳态，"锁 60"意味着无资料片刷新需求
- 参照系：怀旧/时光服双采人工收益约 300–500 金/天（单号），新服首月可能翻数倍，但那是"金币口径"

与正式服对比：
- **金币/小时**：首月无限服大概率 > 正式服（Midnight 12.x 中后期，经济平稳）
- **人民币/小时**：无限服要乘以更低的金价折算且无出口 → **大概率 ≤ 正式服**（正式服至少能徽章锚定 ~75 元/月卡的价值）
- 正式服徽章金币价是收益的"官方汇率"，无限服没有这个锚

## 4. 变现路径（硬事实）

1. **无限服：无时光徽章、无直升**（官方初期口径）。金币目前**没有任何官方出口**——不能换月卡、不能跨服转移（正式服/巫妖王怀旧/20 周年服/永久 60 服的徽章互不流通），只能无限服内消费（买装备/服务/G 团）。
2. **变数（观察点）**：① 官方说"初期不加入"，非"永不"；② 国服测试服已有"时光徽章已到位"的报道（**待官方确认**）；③ 先例：SoD 类时光服已支持金币购徽章换游戏时间（怀旧系首次）。→ 中期开放的门槛不高，但**以官宣为准**。
3. **正式服**：金币→时光徽章→30 天游戏时间，是国服唯一官方"变现"，等值 ~75 元/月，**不能提现人民币**（前期调研已核实）。
4. **金币→人民币**：任何服务器都只有灰产 RMT，违反用户协议（封号+被骗风险），且灰价低。这条路在两个服都不作为建议方案。
5. 账号成本注意：无限服用有效游戏时间即可进入（老账号直接玩），但**没有直升**，练号时间成本自己付。

## 5. 建议：主线不变，无限服走"观察 + 条件触发"

**维持正式服主线**（PLAN.md Phase 0–5 照跑），理由：变现闭环（省月卡）真实存在、飞行采集工程量小、架构已定型。

**无限服备线，三个触发条件，满足任意两个再立项：**
1. **变现信号**：官方宣布无限服加入时光徽章（或国服实测已可购）；
2. **收益信号**：人工基线连续 2 周 ≥ 正式服同口径（金/小时 × 官方锚定价值）；
3. **成本信号**：你愿意先人工投入练 60 级双采号（这一步无论是否自动化都值得，正好顺便记录人工基线数据）。

**现在就做的低成本动作**（不影响主线）：
- 用现有账号在无限服练一个双采号（人工），顺手记录：每小时采集金/物、AH 成交价、上架滞销率——两周后就是决策数据；
- 订阅/关注官方公告与国服无限服徽章动向；
- 若决定立项：技术方案 = PLAN.md 架构 + Classic 客户端适配（重做 PoC 清单）+ 地面导航增强（评估直接研究 WowClassicGrindBot 的 navmesh 路线）。
