# 建筑场景导航推进与验收

目标保持为：大门、室内、走廊、室内门、庭院、楼梯与阁楼等建筑相关场景中，本地识别、局部路线、真实移动和任务流程能够衔接。使用本地检测＋SAM2＋地面语义分割；不接云端模型，不要求人工采点。

## 证据规则

- 局部地面够用即可继续；整幅地面占比、鞋底是否可见不作为必要条件。
- 目标、入口、台阶、房间和楼层分别表示。地图图钉不能说明入口位置，也不能确定同 XY 的楼层。
- `IsOutdoors` 不能确认穿过门；室内门两边都在室内，庭院门两边可能都在室外。
- 平地的投影不能外推到台阶、斜坡或上层平台。先到可测量的连接处，再分段观察、测量和确认位移。
- 看到地面和门洞只产生候选；墙、栏杆、家具、关闭的门、水域和 UI 排除仍然有效。
- 障碍恢复可以先走向可达的侧方/后方观察点，不强制每步接近任务图钉。没有位移反馈时不能继续同一失败动作。
- 缺少标定时的换观察位置，必须另有受限试探或已走通路径证据，不能把图像方向当成精确地图坐标。

## 实现入口

- `bot/perception/building_layout.py`：当前截图中的局部地面、门户、台阶连接及未知楼层；平面导航排除台阶和室内实体。
- `bot/decision/building_navigation.py`：门前可达区域优先；门暂时不可见/不可接近时，选当前已标定、连通、未访问的局部观察位置。
- `experiments/route_models/segmentation_worker.py`：复用驻留本地模型输出布局，进入既有路线计算。
- `bot/control/segmented_detour.py`：沿用帧、位置、朝向、误差和短步预算校验；门户确认绑定门后测量目标与实际移动，不依赖室内标志。中断写明失败条件。
- `bot/control/building_relocation.py`：测量失败时优先沿近期原生实走轨迹回退；无历史时由新鲜局部地面证据启动一次有限后退试探，换位后重新观察，不推算图像尺度。
- `bot/control/building_memory.py`：本次任务内的已核验穿门关系、分区访问/碰撞记录和有界返回观察。区域 ID 是搜索上下文，不是已确认房间或楼层；不跨重启根据 XY 合并。
- `bot/perception/surface_review.py`：检测与 SAM 支持范围内的一次灰度语义复核；保留原始输出及复核来源，保护两种图像都支持的连通水域。
- `bot/perception/portal_review.py`：门洞及周围地面的局部材质复核，保留门板/墙体/台阶证据；可复核的家具误检与新的实体证据分别处理。
- `bot/perception/surface_height.py`：局部原生高度变化的一致性模型，与图像/XY 标定分开验证，不产生楼层身份。

普通房间、走廊、庭院依靠同一局部连通路线，不靠写死左转或右转。台阶只允许规划相邻平地接近点；现阶段不能宣称已支持自动上楼。

这里的 2 码为计划路径上限，实际反馈允许 0.1 码测量/收尾容差，超过即中断；每个历史采样段最多 0.75 码，高度相差超过 0.25 码或未知时不进入本分支。它不支持反向跨越楼梯或从屋顶退下。

换位取消旧图请求、清除旧门洞方向和几何结果，并记录原失败观察位置。到达后重拍、重新测量；旧帧延迟返回不能发键。总时限、无进展计时、移动/观察预算和碰撞记录保持，至少为后续观察保留预算。退开无位移时仅切回有限观察，不再重复回退。
