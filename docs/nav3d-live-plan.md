## 已实现的数据链

`本机 .build.info → CASC → Map.db2 → WDT → ADT 地形与实例 → WMO / M2 碰撞 → 局部 Recast → Detour 完整路径 → TravelCommand`

- 固定 CascLib、wow.export、Map.dbd 版本；构建与只读补丁见 `native/nav3d/casc/README.md`。无 API 密钥依赖。
- CASC 按产品 `wow` 选择本地构建。严格读取校验，不联网补资产、不将缺密钥内容填零。缓存按 Build Key 隔离，读回校验摘要。
- `Map.db2` 解析世界地图身份、Directory 和 WDT FileDataID；WDT 给出实际 tile 文件 ID。uiMapID 只用于界面与同帧一致性，不作资产世界 ID。
- 地形保留高度、低/高精度洞口。水域所在地形 chunk 保守排除；ROI 内 WMO 水体暂时明确拒绝。WMO 使用碰撞/普通渲染面标志，排除 detail 面；兼容 16/32 位索引与新材质标志。M2 仅用碰撞顶点和索引。
- 应用 ADT 实例的位移、旋转和缩放；包含 WMO 全局与选定 doodad set 的 M2 碰撞。实例、源文件、依赖、变换与摘要逐项落盘。邻接 tile 也检查可能跨界的摆放。现代 FileDataID 为主要路径；旧名称索引可显式提供 listfile。
- 三角形裁切到 ROI 后构网。首轮使用起终点包围框加 32 码，最大边长 320 码，仍受四百万水平体素上限约束。没有生成全世界导航网格。
- 不支持的全局 WMO 地图、水体、缺资源、未知模型结构均报错。动态门、运输载具、任务相位替换等不在静态资源证明范围内，不能因此认为当前场景已可通行。

## 遥测与运行边界

插件版本 `0.2.75`。旧旅行 v15/schema 6 保留；新增 `Nav3D.lua` 独立 schema 1，放在主色条右侧 288 像素处，共 26 行。每行 20 位载荷：低 12 位数据、高 8 位序列；跨行序列必须一致。坐标为带符号 24 位百分之一码，字段含世界 ID、build、uiMap、玩家 XYZ、朝向、任务与阶段、世界目标 XY、状态。截取旧旅行与三维通道的同一张图，核验序列、任务、阶段和 uiMap。

`east_north_up = (-UnitPosition 的第二返回值, 第一返回值, Z)`。目标用 `C_Map.GetWorldPosFromMapPos` 转换，返回世界 ID 必须一致。数值、缺失和受限分别编码；公开高度 0 不自动标为可靠地板高度，也不泛化为所有区域都无效。

本机当前位置只有 XY 可用于可靠定位，Z 用网格唯一支撑面初始化。后续要求短距离、连续高度且能通过同一导航网格连接；找不到支撑面或出现上下层歧义即停。日志标记 `inferred_mesh_support`，不把推导高度写成原生实测。

`config/bot.yaml` 已选择 `nav3d-shadow`：

| 模式 | 行为 |
| --- | --- |
| `visual` | 显式使用旧流程 |
| `nav3d-shadow` | 在旧恢复/建筑/接近/战斗动作前接管，只规划、记录并停止，不发送移动 |
| `nav3d` | 三维协调器唯一负责本轮地面导航，经原 `apply_travel_command` / helper 执行；缺对齐/相位证据时拒绝移动 |

预算固定上限 120 秒、最多 3 次重规划；换目标、换世界、失联、入战、坐骑/飞行/下落/游泳等状态停止。转向与短前进均沿用现有 `TravelCommand`，保留 helper 会话授权、前台、急停和松键。`nav3d` 到路径末端仅记录路线到达；普通任务入口停在 `nav3d_route_arrived_waiting_task_receipt`，**没有把路线到达当任务完成，也尚未重新接通完整战斗/交互链**。

实走需 `alignment_file` 绑定 mesh_id、frame，标注 `evidence_kind=live_observation`、`alignment_verified=true`、`phase_verified=true` 和实际 receipts（每项为相对文件路径、SHA-256、kind；需 `native_xy_alignment` 与 `scene_phase` 两类，逐项核验文件摘要）。当前没有创建这样的批准证据。`phase_id=quest:90896:2` 是本轮任务场景标签，不是游戏公开提供的物理相位 ID；物理相位仍须实景核验。

验证结果：1234 项 Python 全量回归、8 个 Lua 回归脚本通过；最后增加的证据摘要保护连同三维相关 67 项定向测试通过；合成几何与协议测试不计作实走。

## 复现

```sh
.venv/bin/python -m bot.nav3d.bootstrap --cmake /path/to/cmake
.venv/bin/python -m bot.nav3d_cli extract-client \
  --client '/Volumes/Mac SSD1/Applications/World of Warcraft' \
  --library data/nav3d/deps/CascLib-build/casc.framework/casc \
  --world-id 2927 --phase quest:90896:2 \
  --roi 2068.6 -920.1 2165 -822 --output data/nav3d/new-roi
.venv/bin/python -m bot.nav3d_cli probe-live \
  --seconds 5 --background-read-only --mesh data/nav3d/new-roi/mesh \
  --output data/nav3d/new-shadow
```

输出路径必须不存在，避免覆盖证据。`probe-live` 不需要输入会话；屏幕读取权限仍必须由宿主提供。正式运行继续使用现有“WoW 键鼠 → 授权并运行已准备任务”入口，按配置选择模式。
