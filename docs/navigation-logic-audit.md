# 导航与接近操作逻辑审计（2026-11-17）

用户纠正：草丛、水面和特效会遮住角色脚点，“识别不到脚下地面”不能直接作为停止规划的理由。本轮检查分割地图、图像搜索、地图投影、NPC 接近、短步移动回执，以及飞行/游泳/拾取相关状态门槛。不是对所有任务和职业的完整实机审计。

## 已修复：代码与离线验证，实机待验证

## 仍存在的能力缺口，不能称为已修复

1. **水域专用移动**：现有旅行和 NPC 接近仍拒绝游泳状态；水面识别不等于深度、岸线或游泳能力已确认。本轮只把水域证据独立出来，没有凭截图自动进入游泳模式。需要专用状态机、岸线/落点与实机位移验证。
2. **图像轮廓不是地面碰撞占地**：木桩上端、倾斜栏板、树冠都带高度。当前实体像素是保守视觉轮廓，不能全部直接当作同平面世界障碍边界。仍需落地点/多视角几何与实际碰撞证据。
3. **固定像素身体余量随镜头变化**：图像搜索当前默认身体半径 8 px、误差 4 px。这是图像候选的参数，不是已测角色碰撞半径；实际运动前需要根据镜头/标定尺度和角色状态核对。
4. **真实标定和自动目标位置**：0.2.68 已接入原地相机旋转中心测量、不同方向原生位移拟合和独立运动验证，移除运行时人工标定包。自动 NPC 候选/任务搜索区域已接入，地图标记仍不是精确 NPC 位置；互动范围单独确认。当前缺的是游戏内验证，不能把合成几何回归当作真实标定成功；跨地图长期测量复用和真正动态目标定位仍有限。见 `docs/ground-calibration.md` 的当前任务入口。
5. **跨层/跨平面和动态遮挡**：原生 XY 接近不证明在同一楼层；单平面标定不能用于坡道转折、深水或飞行。移动 NPC、镜头挤压及新碰撞要求重建证据。

## 验证边界

新增回归覆盖：遮挡角色绕实体墙到目标区域、优先已知通路、NPC 身体未知仍可接近、禁止擦除硬障碍/未知地形、旧轨迹拒绝、失效镜头/曝光拒绝、投影后的短段预算、缺反馈不确认移动、原生范围中断旧绕行、到图钉搜索区不冒称完成、分割文件与曝光绑定。

真实截图重放仍为同一张参考图，栅栏覆盖 82.2%、IoU 79.3%，保留原分割结果；新增的遮挡/水域分类没有独立真值，不能据此宣称通路已成功。没有把人工脚点、假定半径或合成标定套到当前游戏截图上制造绕栏成功。

证据目录：`data/terrain/approach-logic-20261117/`。本轮不操作游戏，不安装插件，不启用云端模型。最终测试结果见该目录的 `regression.xml` 和 `validation.json`。

全量 596 Python 通过（23.68 秒）；最后增加的水域模式错误分类与原地核对范围行为另通过 29 项针对性测试，6 Lua 脚本通过。一次旧回归因仍要求先走进图钉 1.5 码而失败，已把场景更新为“从 5.5 码进入 3.5 码搜索区”，保留选中、原生范围、交互和交付的全部断言，没有删掉交付检查。
