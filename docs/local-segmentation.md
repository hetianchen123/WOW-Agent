# 本地识别模型接入与地图回放

2026-11-17，遵循用户“分割模型识别 → 本地计算路线，不接大模型 API”的要求。现已接通任务卡点内自动标定、地图掩码、本地搜索与短步反馈，不需要人工标定包或 NPC 区域登记；完整自动绕栏仍待实机。当前运行方式见 `docs/ground-calibration.md` 开头，以下保留各阶段截图评测记录。

## 模型与部署

- [Grounding DINO tiny](https://huggingface.co/IDEA-Research/grounding-dino-tiny)：自动检测木栏、木桩、尖刺、岩石、树木、灌木和人物。固定文字类别提示，不调用生成式大模型或云端推理。revision `a2bb814dd30d776dcf7e30523b00659f4f141c71`。
- [Meta SAM 2.1](https://github.com/facebookresearch/sam2)：用自动框分割实例，比较 tiny 与 large，默认回放选择 large。每个框保留候选分数，按模型分数选掩码，不用人工轮廓挑选最好结果。
- [SegFormer B2 ADE20K](https://huggingface.co/nvidia/segformer-b2-finetuned-ade-512-512)：提供草地、道路、泥土等地面候选及语义类别。revision `de01bae28967510f9ddd496c60a969357195400c`。并未针对魔兽训练。

独立环境 `data/segmentation/.venv`，CPU 4 线程；本轮 Torch 2.15.0、Transformers 4.57.6、SAM-2 1.0。权重全部来自上述官方发布来源，代码只读本地权重。SAM 3 官方权重受访问授权限制，当前未发现本地权重或授权凭据，因此本轮未运行 SAM 3，不计入模型失败或成功。

`LocalSegmenter` 在实例内复用已加载模型；Torch/Transformers 延迟导入，不增加主控必需依赖。模型路径及固定 revision 在 `data/segmentation/models.json`，每份回放报告记录 SAM 权重 SHA256、输入图 SHA256、检测框、所有候选分数和耗时。截图未上传。

## 地图与搜索边界

`bot/perception/segmentation.py` 输出三个互斥布尔掩码：实体障碍、视觉候选地面、未知。地面要求语义置信度至少 0.8、前两类别差至少 0.2；这些阈值是开发规则，不是碰撞概率。树冠、人物等表示遮挡，不当作已知实体占地；未被分割覆盖的检测框内部保留未知，不能让语义草地填掉木栏的漏检部位。低分实例也保留未知。

`ImageNavigator.from_masks` 直接读取像素掩码并留出身体/不确定余量，保留掩码孔洞、薄障碍和未知区域，不先取外轮廓填洞。所有路线仍 `executable=false`。语义地面分类不等于游戏实际可走，掩码外观也不等于真实碰撞网格。

当前地图识别不包含可用的玩家/NPC 自动身份定位。只有独立参考图可使用人工复核脚点进行**隔离路线探测**，报告标明 `manual_review_not_automatic_localization`；参考轮廓在推理完成后才读取用于评分，不传给检测器/分割器。无法确认起点时不会挪动脚点或清空附近障碍以求路线成功。

这里是**最终融合地图**对人工保守栅栏轮廓的评分，不是 SAM 单独原始掩码分数，也不是游戏真实碰撞召回。tiny 的主木栏掩码分数低于 0.85，主体保留未知，因此不能直接和旧实验中 tiny 原始掩码约 53%–60% 比较。所有模型选择和阈值均未使用人工评分反馈来修补输出。

三种组合在这张参考图上均没有把标注栅栏像素标为地面，遗漏部分主要为未知；不能据此声称其他画面也不会漏障。large 地图的候选地面约 37.1%、未知约 59.5%。仍有木栏部件漏识别，且目标、角色、树冠附近未知范围过大，没有形成可用的起点到 NPC 通路。

另测同曝光完整窗口及一张低视角旧图，不使用错图参考标签打分。完整窗口可将动作栏图标误检为木栏；低视角仍存在遮挡和不完整实体识别。它们只用于暴露取景/UI 限制，不能算独立通过场景。没有人工地面真值，因此尚不能量化错误可走面积，单图栅栏结果也不证明泛化。

局部放大比全图差，保留为对照选项，默认关闭；没有只挑最好结果隐藏失败。本批不安排自动任务实测。

## SAM 2 第一轮优化（2026-11-17）

用户要求优先优化现有 SAM 2，不等待 SAM 3。本轮仍为保存截图的本地回放，不操作游戏、不启用云端路线 API；优化通过 `--optimize` 显式启用，旧回放默认行为保留。

### 实现与边界

- **完整结构提示**：对自动检测的实体框按最长边 15% 向四周扩展上下文，在同一个全图 embedding 上再次分割，不裁剪放大。只接纳原掩码分数和新掩码分数均 ≥0.85、保留原结构 ≥95%、面积为原图形 1–2 倍的候选；与原掩码取并集，不擦除旧实体、不填洞。原始框、候选分数、保留率、面积变化及拒绝记录全部保存。模型分数仍不是碰撞概率。
- **空白区域补证据**：从已有高置信地面内部选择最多三个点做 SAM 地面分割；图像边缘不算地面延续。只有 SAM 分数 ≥0.9、包含提示点、语义地面同时达标，才允许解除高分人物/树冠检测框的空白边缘；遮挡掩码周围保留 8 px 余量。实体框、混合实体/遮挡标签及低分遮挡框一律不开放。新增 `ground_evidence` 掩码用于审计；这仍只是视觉候选，尚无独立地面真值验证。
- **UI 排除**：支持按截图 SHA256 绑定的二值 UI 掩码；先保留原始画面推理，过滤 ≥90% 被 UI 覆盖的检测框，最终 UI 始终未知。当前对照的 UI 位置由人工仅标注界面，不是自动定位，也没有向模型提供木栏/地面参考。曾试验涂灰 UI，栅栏覆盖降到 77.2%、IoU 降到 63.6%，已撤掉这种实现，失败产物保留。
- **GPU**：`--sam-device mps` 仅将 SAM 放到 Apple GPU，检测和语义模型仍在 CPU。不可用时报明确错误，不隐藏回退。加载、首次预热和后续耗时分别保存。`local-detail` 与优化模式互斥，避免在局部 embedding 上继续使用全图坐标。
- **拒绝原因**：报告增加起点/终点语义类别、置信度和 12 px 邻域内地面/实体/未知比例。手工脚点只用于隔离探测，不是已实现自主定位。
