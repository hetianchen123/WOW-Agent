# WowAgent 长期推进清单

更新：2026-11-17。目标是支持范围内的普通任务和逐类接入的战役专项能顺畅完成。
团本、大秘境不在本计划内。当前职业为猎人兽王/生存，起始区域为地图 2451。

## 推进规则

依赖：M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8。
状态只使用：待开发、已实现、离线通过、实机通过、回归失败。
一阶段的关键实机失败先修复，才推广依赖它的能力；等待用户实测时可准备后续独立代码和样本。
每次发布保留回退包、核对安装和运行版本，然后通过脚本做一次或多次 10–20 分钟定向实测。
模拟、真实截图离线推理、游戏实机结果分别记录，不能互相替代。

### 状态与职责

流程：停步分类 → 选择脱困方向 → 分段退离 → 核验观察空间 → 规划局部通路 → 接回原任务。脱困只解决当前位置难以观察/行动的问题，不要求此时看清通往 NPC 的完整路线。

1. **停步分类**。释放移动，保留任务、目标身份、原阶段、碰撞位置与失败方向。分别记录构图异常、玩家定位未知、近处通路未知、已确认阻挡；`feet=null` 不能自行触发镜头恢复。真正构图异常保留一次预设恢复；普通遮挡进入脱困。
2. **选择脱困方向**。优先倒序回到最近实际走过的落脚位置，其次选择画面支持的侧后短步，再考虑原地补看左右各一个方向。选择标准是可退离、可观察、风险和所需转向，不是离 NPC 最近。脚点不是唯一证据，但必须存在另一种明确的移动依据。
3. **分段退离**。路径在角色正后方才使用 S；斜后方须先核对朝向或已验证的横移键，不能将固定 S 当作原路回退。每段移动后松键，等新鲜导航序列核对位移大小、方向和角色状态。脱困阶段允许任务标记距离增加，普通 NPC 接近的“距离不减”检查暂停，交由脱困控制器独占移动。
4. **核验观察空间**。先累计约 2 码或在画面明显改善时停稳重看，通常争取退开 2–4 码；不为凑距离继续走。检查能否定位玩家所在区域、看清相邻地面和至少一个可复核的短步方向。只有位移而没有观察改善，只算移动成功；最多换一次有依据的方向，不在原地反复大角度扫描。
5. **规划局部通路**。从新位置找入口、栅栏端点、墙角外侧或道路，不立刻朝 NPC 图钉直走。旧截图/屏幕点全部失效，已碰撞方向仍保留。唯一候选直接转向复核，多个有效候选才交 StartLux 排序；候选屏幕点不能直接变成世界坐标。通过短步与新位移确认后，逐段形成实际通路。
6. **接回原任务**。到达绕行点后重新核对目标身份和接近条件；NPC 仍以原生互动范围与交付回执验收。分开记录“退离有位移”“观察改善”“通路走通”“任务交付”。入战/死亡交回对应恢复流程并取消旧模型请求；恢复后重建观察。失焦、急停、输入失效和数据失联仍释放并停止。
