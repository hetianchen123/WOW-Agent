# 路线标注地图

用于手工标注区域间的步行、骑马和飞行路线。无限服 0.2.108 支持原生世界地图截图取路和室外主路优先。

## 使用

1. 输入 `/waroad`，或打开 WowAgent →「任务与色条」→「地图主路标注」。编辑窗口可拖动，世界地图保持原有底图。
2. 填写路线名称、起点区域、终点区域，点击「步行」「骑马」「飞行」选择整条路线的方式，选中项带方括号；另选双向或起点到终点单向。需要不同方式的路段时分别保存路线。
3. 在世界地图切到目标区域，点击「开始地图标点」。沿路依次左键添加点，右键或「撤销末点」撤销。弯道、桥头、山口、入口处加密标点，避免折线切过山体。编号代表行进顺序；绿色线与「步」代表步行、黄色线与「骑」代表骑马、蓝色线与「飞」代表飞行，均为人工标注、通行尚未验证。
4. 点击「结束标点 / 浏览地图」后，正常拖动、缩放或切换地图。需要跨地图时，先在旧地图标出口，切换到相邻地图，开启「跨图连接」，再标入口。跨图连接显示菱形，不把不同地图的坐标画成一条直线；它仅声明人工指定的边界连接，不代表已经验证连通。
5. 「添加脚下位置」可补充当前角色所在点。单点采样不是完整走路录制，也不证明两个采样点之间可通行。
6. 点击「保存路线」。用「上一条 / 下一条」载入已存路线继续编辑，「显示末点地图」回到当前路线末端。每条最多 512 个点，每个服务器/客户端组合最多 100 条路线。

草稿会保留在插件数据中，关闭窗口后重新打开继续编辑。「新建」或载入其他路线前的草稿保留在一个恢复槽中，点「恢复草稿」切回。删除已存路线仍保留当前工作草稿，立即点「保存路线」可以重新保存；这不是无限历史撤销。

0.2.72 修正地图打开流程：所有入口调用原生地图打开接口，检查地图可见、画布尺寸与目标地图；布局延迟时最多等待 2 秒。地图关闭时点击「开始地图标点」会先打开地图，就绪后才接受标点。调用报错或地图未显示会在面板和聊天中提示，不把请求发送当作地图已打开。旧客户端没有新接口时使用原生面板管理器；战斗中不强制操作受限面板。

## 保存和迁移

数据位于账号 SavedVariables 的 `WowAgentDB.roads`，schema 为 1。游戏执行 `/reload` 或正常退出时才将内存数据写入 `WTF/Account/<账号>/SavedVariables/WowAgent.lua`；崩溃前未写盘的数据可能丢失。

路线按 `客户端项目 ID:服务器名称` 隔离。每点保存 `mapID`、归一化 `x/y`、可读时的 `artID`、来源；跨图入口保存 `transition="boundary"`。每条保存名称、起终区域、方向、旅行方式、客户端版本及 `manual_unverified` 证据状态。地图点击使用当前查看地图；脚下采点使用玩家实际地图。地图美术阶段不一致时不展示对应点。

三种方式的数据值为 `walk`（步行）、`ground`（骑马）、`fly`（飞行）。0.2.70 的「骑马 / 步行」保留原 `ground` 值，新界面显示为「骑马」，可按需改为步行；原步行路线继续保留。飞行标记不提供高度数据，也不表示当前区域允许飞行或角色已经具备飞行能力。

更换服务器时保留原 SavedVariables 作为备份。无限服单独建库。正式服标注需要重新核对地图、美术版本和连接位置，才能用于无限服。

## 无限服自动取路

使用「一键准备自动任务」和已有键鼠入口运行。首次读到无近期缓存的室外区域地图后，主控短暂停步。插件以原生接口打开当前地图，核对地图编号、地图美术、缩放及完整画布，再用四角校准截图。取图时暂隐与地图重叠的任务、战斗、旅行和三维色条，结束后恢复。战斗、施法、游泳、下落以及未关闭的对话或地图编辑界面会推迟采样。

本地 Qwen3-VL 提出道路折线，OpenCV 搜索附近连续的可见路迹并修正路点。首次识别时主控最多等 12 秒，之后推理继续在后台运行。结果按服务器、客户端构建、地图 ID 和地图美术编号写入 `data/roads/forever/`，其中包含原图、模型记录、归一化坐标和标注图。世界地图尚未探索的区域只会留下当前画面可识别的部分。主控在本轮即可使用新坐标，插件的 `/waroad` 面板在下次 `/reload` 后显示青色标注。人工保存的步行、骑马线路在写盘后可参与同地图匹配。

同一轮缺少可用路点时，脚本可在离首次取图或读到缓存的位置至少 220 码、且间隔至少 60 秒后重拍一次。沿用上轮缓存且缓存已超过 60 秒时，长途行程首次匹配失败便可在当前位置补拍一次。重拍只等待地图开关及画布验证，识别在后台完成。识别得到不同道路后，正在走室外备选路线的行程会重新匹配。地图画布取自游戏窗口，前台校验、桌面色条心跳和键鼠目标校验仍在托管入口执行。

室外长距离跑图优先用已有路网计算接入、沿路和离开主路的航点，并保留可用飞行优先级。路网覆盖部分行程时，可沿有效路段前进，到最后一个已标路点后重新规划剩余行程。碰撞、偏离或无进展会释放前进，交回现有地面规划和局部绕障。室内、洞穴及跨地图出入口由对应流程处理。地图线条只提供候选路径，实际是否通行以角色位移为准。
